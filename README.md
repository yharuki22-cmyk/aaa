# 建築材料学 4択問題演習アプリ

建築材料学の試験勉強用の、**PDF対応・4択問題演習Webアプリ**です。
試験範囲のPDFを読み込ませると、**線引き・ハイライト箇所を優先的に**使用して、
毎回異なる4択問題を10問出題します。答え合わせ・解説・出典表示・学習履歴・復習モードに対応しています。

---

## 特長（できること）

- 📄 **PDFのアップロード**（複数可・ドラッグ＆ドロップ対応）
- 🖍 **線引き/ハイライトの優先抽出**
  - PDFのハイライト注釈・下線注釈を直接抽出
  - 画像として埋め込まれた蛍光ペン/下線を色検出（可能な範囲で）
  - 文字情報の無いスキャンPDFはOCR（Tesseract.js）で読み取り
  - 線引きが見つからない場合は**全文から重要事項を抽出**（その旨を画面表示）
- 📝 **4択問題を10問生成**（A/B/C/D、正解は必ず1つ、正解位置はA〜Dへ分散）
  - 出典（PDF名・ページ・原文抜粋）を各問題に紐づけ
- ✅ **答え合わせ・採点・解説**
  - 正解/不正解、あなたの回答、正しい回答、日本語解説、誤答が誤りの理由、根拠原文を表示
  - 「10問中○問正解」と正答率を表示
- 🔁 **問題の更新（次の10問）** … 直近の出題と重複しない問題を生成
- 📊 **学習履歴** … 総回答数・正解数・正答率、PDF別/分野別の正答率、**復習モード**
- 🔒 **AIは任意**。APIキーが無くても**ローカル生成モード**で動作（オフライン）
- 📱 スマホ/PC両対応のレスポンシブ・落ち着いた配色（色＋文字/記号で正誤判別）

## 技術構成

| 項目 | 採用技術 |
| --- | --- |
| フレームワーク | Next.js 14 (App Router) |
| 言語 | TypeScript |
| スタイル | Tailwind CSS |
| PDF処理 | pdfjs-dist（テキスト・注釈抽出、ページ描画） |
| OCR | Tesseract.js（jpn+eng） |
| データ保存 | IndexedDB（`idb`）※解析結果・学習履歴を保持 |
| 入力検証 | Zod |
| テスト | Vitest |
| AI（任意） | OpenAI互換 Chat Completions API（**サーバー側API Routeで実行**） |

> **なぜこの構成か**：Windowsで `npm run dev` だけで起動でき、
> APIキーをサーバー側（API Route）に隔離できるため、ブラウザからキーが見えません。
> PDF解析・OCRはブラウザ内で完結し、AI未設定でもローカル生成で動作します。

## 🪟 Windowsでの起動手順（初心者向け・コマンドを順番に）

1. **Node.js をインストール**（[https://nodejs.org/](https://nodejs.org/) の「LTS」版）。
   インストール後、`PowerShell`（または`コマンドプロンプト`）を開いて確認：
   ```powershell
   node -v
   npm -v
   ```
   バージョン番号が表示されればOKです。

2. **このフォルダに移動**（例：ダウンロード先が `C:\Users\あなた\aaa` の場合）：
   ```powershell
   cd C:\Users\あなた\aaa
   ```

3. **必要なパッケージをインストール**（初回のみ・数分かかります）：
   ```powershell
   npm install
   ```

4. **アプリを起動**：
   ```powershell
   npm run dev
   ```

5. ブラウザで **[http://localhost:3000](http://localhost:3000)** を開く。

6. 終了するときは、PowerShellで `Ctrl + C` を押します。

> うまく動かないときは、`npm install` をもう一度実行してから `npm run dev` を試してください。

## 📄 PDFの入れ方（使い方）

1. アプリ画面上部の「**1. PDFをアップロード**」から、
   PDFファイルを**ドラッグ＆ドロップ**するか「**ファイルを選択**」で選びます（複数可）。
2. 「解析中…」の進行状況バーが表示され、テキスト・線引きの抽出が行われます。
3. 解析が終わると、そのPDFに「✔ 線引き/ハイライトを検出」または
   「⚠ 線引き未検出：全文から重要事項を抽出しました」と表示されます。
4. 「**2. 問題を出題**」の「**10問を出題する**」を押すと、4択問題が10問表示されます。
5. すべて回答して「**答え合わせ**」を押すと、採点・解説・出典が表示されます。
6. 「**問題を更新（次の10問）**」で、重複しない新しい10問に切り替わります。

> **線引きを優先させるには**：PDFビューア（Adobe Acrobat等）で本文に
> **ハイライト（蛍光ペン）注釈**を付けて保存したPDFを読み込ませると、その箇所が優先的に問題化されます。

## 🤖 AI（生成AI）のAPIキー設定方法（任意）

APIキーを設定しなくても、抽出した文章から**簡易問題を作るローカルモード**で動作します。
より高品質な問題・解説が欲しい場合のみ、以下を設定してください。

1. `.env.example` をコピーして `.env` を作成：
   ```powershell
   Copy-Item .env.example .env
   ```
2. `.env` をテキストエディタで開き、値を設定：
   ```env
   AI_ENABLED=true
   AI_API_KEY=（あなたのAPIキー）
   AI_BASE_URL=https://api.openai.com/v1
   AI_MODEL=gpt-4o-mini
   ```
   - **OpenAI以外**（OpenRouter、Azure、ローカルLLMのOllama等）でもOpenAI互換なら `AI_BASE_URL` を変えるだけで利用できます。
3. アプリを再起動（`Ctrl + C` → `npm run dev`）。

**セキュリティ上の設計**
- APIキーはソースコードに書かず、`.env` から読み込みます。
- `.env` は `.gitignore` によりGit管理対象から除外されます（コミットされません）。
- AIの呼び出しは**サーバー側（API Route）でのみ**実行し、ブラウザにキーは渡りません。
- AIへ渡すのは**問題作成に必要なPDF抜粋のみ**です。
- AIの返答はJSONで受け取り、**Zodでスキーマ検証**します。
  正解番号が範囲外・選択肢が4つでない・正解が重複するなどの**不正な問題は破棄**します。
- **AIを有効にすると、PDFの抜粋が外部サービスへ送信されます**。
  この点はアップロード画面にも注意書きを表示します。機密PDFの取り扱いにご注意ください。

### 設定を変えたいとき（初期設定の変更方法）
- **1ファイルの上限サイズ**：`src/lib/pdf/fileValidation.ts` の `MAX_FILE_SIZE_BYTES`（既定20MB）
- **1セットの問題数（10問）**：`src/lib/store/useQuizApp.ts` の `QUESTIONS_PER_SET`
- **AIモデル/接続先**：`.env` の `AI_MODEL` / `AI_BASE_URL`
- **配色**：`tailwind.config.ts` の `colors`

## 🖍 線引き（ハイライト）認識の制限事項

- **PDF注釈のハイライト/下線**が最も高精度です（Acrobat等で付けた蛍光ペン注釈）。
- **画像として描かれた蛍光ペン/下線**は色（黄・緑・桃・橙）で検出しますが、
  薄い色・特殊な色・文字と重なる場合などは検出できないことがあります（「可能な範囲で」の対応です）。
- ハイライト範囲と本文テキストの対応付けは座標ベースの近似のため、
  複数行や回転ページでは抜粋が前後の語を含む/欠けることがあります。
- **スキャンPDF（画像のみ）**はOCRで読み取りますが、初回はOCR用の言語データ取得に
  ネットワークが必要で、認識精度・処理速度はPDFの品質に依存します。
- 線引きが1つも検出できない場合は、**全文から重要事項を抽出**して出題し、その旨を画面に表示します。

### 実装済みの主なテスト
- 10問生成されること
- 各問題に4つの選択肢があること／正解がちょうど1つであること
- 採点結果（正解数・正答率・未回答検出）が正しいこと
- 解説とPDF出典（PDF名・ページ・原文抜粋）が含まれること
- 更新時に直近の問題と重複しないこと
- 学習履歴の集計・（空＝リセット後の）ゼロ表示・復習モード抽出
- 不正なAI応答を破棄できること
- PDF以外のファイルを拒否できること

## データの保存とリセット

- 解析結果・学習履歴・出題履歴は**ブラウザのIndexedDB**に保存され、
  ページを再読み込みしても維持されます。
- 「**出題履歴をリセット**」ボタンで、回答履歴・出題済み記録を消去できます（解析済みPDFは残ります）。
- PDFの**ページプレビュー**は、そのセッションでアップロードしたPDFに対して表示できます
  （再読み込み後は同じPDFを再アップロードすると再び表示可能）。

## プロジェクト構成（抜粋）

```
src/
  app/
    page.tsx                # メイン画面
    layout.tsx / globals.css
    api/
      ai-status/route.ts    # AIが設定済みか返す（キーは返さない）
      generate/route.ts     # サーバー側でのみAI生成を実行
  components/               # 画面部品（アップロード/問題/採点/履歴/プレビュー）
  lib/
    pdf/                    # PDF解析・OCR・画像ハイライト検出・ファイル検証
    quiz/                   # 型・スキーマ・ローカル生成・検証・採点・重複排除・プロンプト
    history/                # IndexedDB・履歴集計
    store/useQuizApp.ts     # アプリ状態のまとめ役（Reactフック）
  test/                     # Vitest テスト
scripts/copy-pdf-worker.mjs # pdf.js ワーカーを public/ にコピー
```

## 注意

- 学習補助ツールです。生成された問題・解説は**アップロードしたPDFの記載のみ**を根拠にしていますが、
  抽出・生成の性質上、誤りが含まれる可能性があります。最終的な正誤は原典（PDF・教科書）でご確認ください。

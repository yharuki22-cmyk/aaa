# 図面写真 → AutoCAD DXF 自動生成(参考DWG学習版)

寸法の書かれた図面写真(配置図兼1階平面図 S=1:100)と、参考例のDWGから、
AutoCADでそのまま開けるDXFを生成する。

## 仕組み

```
参考DWG ──(Aspose.CADでDXF化)──> extract_reference.py
                                       │  幾何レイヤを抽出・実寸mmへ校正
                                       ▼
                             reference_geometry.json
                                       │
図面写真の寸法・注記 ──────────> generate_dxf.py
                                       │  文字・寸法・通り芯を再構築
                                       ▼
                          output/site_floor_plan.dxf
```

- **幾何**(壁・柱・建具・設備機器・家具・外構・境界線)は参考DWGの実データを
  実寸mmに変換して取り込み
- **文字・寸法・通り芯**は参考DWGでは線分に分解されていたため、本物の
  TEXT / DIMENSION / LINE として再構築(AutoCAD上で編集可能)
- 植栽は参考DWGに無かったので写真からの目測

## 縮尺の校正

参考DWGの図面単位を、通り芯グリッド(910mmモジュール)から校正した
(1単位 = 25.53276mm)。検算:

| 項目 | 校正後の実測 | 図面の寸法値 |
|---|---|---|
| い〜り通り | 7,280.0 | 7,280 ✓ |
| り通り〜道路境界線 | 2,000.0 | 2,000 ✓ |
| 6通り〜北側境界 | 2,500.0 | 2,500 ✓ |
| 敷地 奥行 | 12,500.1 | 12,500 ✓ |
| フェンス控え | 100.0 | 100 ✓ |
| 敷地 幅 | 10,980 | **11,000** ← 元図のずれ |
| 0〜6通り | 5,480 | **5,460** ← 元図のずれ |

元の参考DWG自体に2箇所だけ作図のずれがある(敷地幅が寸法値より20mm狭い、
0通りの外壁が通り芯より20mm南)。幾何は元図のまま取り込み、寸法値は
図面の表記(11,000等)に合わせている。

## 使い方

```bash
pip install ezdxf matplotlib
python generate_dxf.py        # → output/site_floor_plan.dxf
python render_preview.py      # → output/preview.png(確認用)

# 参考DWGから幾何を再抽出する場合 (DWG→DXX変換済みファイルが必要)
python extract_reference.py reference.dxf reference_geometry.json
```

DXFは単位mm・実寸1/1。AutoCADで開いて `SAVEAS` すればDWGになる
(DXF⇔DWGは形式の違いだけで精度は同一)。

## 画層構成(参考DWGに準拠)

01通り芯 / 02柱・壁(断面線) / 03開口断面線 / 04開口見えがかり線 /
05設備機器 / 07家具 / 08文字 / 09寸法 / 10線一般(中線) / 12切断線 /
13境界線 / 14図枠 / 16外構

※元図で12切断線レイヤに描かれていた敷地境界の矩形は13境界線へ移動済み。

## 制限

- 円弧(ドアの開き軌跡など)はDWG変換の時点で短い線分列になっている
  (見た目は同じだが、AutoCAD上でARCとしては編集できない)
- 文字・寸法の配置は写真を参考にした再構築で、元図と数mm単位では一致しない

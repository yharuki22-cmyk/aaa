# 図面写真 → AutoCAD DXF 自動生成プロトタイプ

寸法の書かれた図面の写真(配置図兼1階平面図 S=1:100)をAIで読み取り、
**写真のトレースではなく寸法値から正確に再作図**したDXFを生成するプロトタイプ。

## 仕組み

```
図面写真 ──(AIが寸法・構成を読み取り)──> plan_data.py(構造化データ)
                                              │
                                              ▼
                                        generate_dxf.py
                                              │
                                              ▼
                                 output/site_floor_plan.dxf ──> AutoCADで開く
```

- `plan_data.py` — 写真から読み取った寸法・部屋構成。**ここを直せば図面も直る**
- `generate_dxf.py` — ezdxf でDXFを生成(画層・通り芯・寸法スタイル付き)
- `render_preview.py` — 確認用PNGを出力

## 使い方

```bash
pip install ezdxf matplotlib
python generate_dxf.py        # → output/site_floor_plan.dxf
python render_preview.py      # → output/preview.png(確認用)
```

生成されたDXFはAutoCADでそのまま開けます(単位mm、実寸1/1。1:100は印刷時に設定)。

## 読み取った主な寸法

| 項目 | 値 |
|---|---|
| 敷地 | 11,000 × 12,500 |
| 通り芯 | X: い〜り 9本 @910 / Y: 0〜6 7本 @910(5,460) |
| り通り〜道路境界線 | 2,000 |
| テラス出 | 1,000 |
| 北側境界〜駐車場 | 2,500 |
| フェンス | アルミフェンス H=900 |

## 画層構成

敷地境界(PHANTOM) / 通り芯(CENTER) / 壁 / 室名 / 寸法 / 外構 / 図枠

## 現状の制限(プロトタイプ)

- 建具(ドア・窓・引違い記号)、階段の段割り、設備機器(便器・浴槽・キッチン)は未作図
- 壁は太線1本の簡易表現(二重線・仕上げ表現なし)
- 駐車場・植栽の位置は写真からの目測(寸法記載がないため)
- ハッチング(ポーチのタイル目地など)は未対応

寸法が写真から読み取れなかった箇所は `plan_data.py` のコメントに「推定」と
明記してあるので、正しい値に差し替えて再実行してください。
